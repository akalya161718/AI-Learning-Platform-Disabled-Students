# AI Learning Platform for Disabled Students

## Project Overview

This project is an AI-based learning platform designed to provide accessible and personalized educational support for students with disabilities.

## Features

* Voice-based learning support
* Text-to-speech and speech-to-text features
* Accessible content navigation
* Interactive quizzes and feedback
* Personalized learning experience

## Technologies Used

* HTML
* CSS
* JavaScript
* Artificial Intelligence Concepts
